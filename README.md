

# 📰 Personalized News Aggregation App

A mobile news app built using **Flutter** and **Dart**, designed to deliver personalized, real-time news updates based on user interests. The app is easy to use, supports daily updates, and offers features like category-wise news, commenting, and more.

---

## 📱 Features

- 🔐 **User Authentication** – Sign up, log in, and manage accounts securely.  
- 🧭 **User-Friendly Interface** – Simple and clean UI built for smooth navigation.  
- 🎯 **Interest-Based Recommendations** – Personalized news feed based on selected topics.  
- 🔍 **Search by Category** – Explore news by genres like Sports, Tech, Politics, etc.  
- 🗞️ **Daily News Updates** – Stay up-to-date with the latest happenings every day.  
- 💬 **Comments & Discussion** – Engage with other users on news articles.  
- 📤 **Share Articles** – Share interesting news with friends via social media.

---

## 🔧 Tech Stack

- **Flutter** (Dart) – Cross-platform app development  
- **Firebase** – Authentication, database & storage  
- **REST APIs** – For fetching real-time news  
- **VS Code / Android Studio** – Development IDEs

---

## 📦 Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/ShreyasChavan1/news_app.git
   cd news_app
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

---

## 🎯 Purpose

The goal of this app is to offer users a more **personalized**, **organized**, and **engaging** news reading experience with modern features that go beyond traditional news apps.
